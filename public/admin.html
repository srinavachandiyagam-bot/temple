Admin / Deployment Settings

For security, the admin password and Cashfree secret must be configured as server environment variables. They should not be stored in this HTML page.

ADMIN_PASSWORD — admin login password
CASHFREE_CLIENT_ID — Cashfree Client ID
CASHFREE_CLIENT_SECRET — Cashfree Client Secret
CASHFREE_ENV — sandbox or production
PUBLIC_BASE_URL — public HTTPS website URL for payment return/webhooks

You can change all contact names and numbers above. Before going live, use HTTPS, change the default admin password, configure Cashfree Production credentials, and set the webhook URL in Cashfree.
